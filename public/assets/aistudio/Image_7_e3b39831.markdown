## Brand & Style

This design system is tailored for an enterprise-grade logistics, freight tracking, and operational billing platform. It conveys dependability, high operational throughput, algorithmic clarity, and friction-free data management. The primary users are fleet managers, dispatch coordinators, billing analysts, and enterprise account administrators processing thousands of manifests, shipments, and ledger balances.

The visual style is **Corporate / Modern Enterprise SaaS**:
- High-clarity white canvas (`#FFFFFF`) framed with subtle slate-tinted containment borders.
- Crisp utilitarian structure that maximizes data density while retaining rapid scannability.
- Fastway operational blue as the anchor for primary interactions, paired with a vibrant jade/teal accent reserved for liquidity events (e.g., wallet balance, top-ups, transaction success status).
- Ultra-legible typography, compact data-grid paddings, and distinct active navigation pills.

## Colors

The color palette reinforces the enterprise logistics workflow:
- **Primary (`#1E70EB` / `#1877F2`)**: Utilized for actionable focal points, primary table operations (e.g., "Invoice" action buttons), selected state indicators, interactive links, and top-tier badge highlights.
- **Secondary (`#10B981` / `#059669`)**: Reserved for affirmative states, "Sent Payment" actions, positive account balances, and "Success" status badges.
- **Tertiary & Headers (`#0F172A` / `#1E293B`)**: Ultra-dark navy-slate used for critical metric values, section headings, and active tabular IDs (`#100000...`).
- **Neutral Foreground (`#64748B`)**: Slate gray used for secondary labels, table headers, breadcrumb elements, metadata dates, and form helper descriptions.
- **Surface & Backgrounds**: Base background is pure white `#FFFFFF` with secondary canvas panels at `#F8FAFC`. Card surfaces use pure `#FFFFFF` separated by thin `#E2E8F0` hairline borders.
- **Status Accents**:
  - *Success Badge*: Fill `#ECFDF5`, Border `#A7F3D0`, Text `#059669`.
  - *Active Tab / Pill*: Fill `#0F172A`, Text `#FFFFFF`. Inactive pill: Background `#FFFFFF`, Border `#E2E8F0`, Text `#64748B`.
  - *Primary Nav Selected*: Fill `#EBF3FE`, Text `#1E70EB`, Icon `#1E70EB`.

## Typography

The typography scale utilizes **Inter** throughout all tiers to guarantee uniform numeric rendering, crisp vertical alignment, and legibility at compact enterprise scales (11px–13px).

- **Data Tables**: Table header text is 12px with semi-bold weighting (`600`) in slate `#64748B`. Standard table cell data is rendered at 13px (`#334155`), while unique identifiers (e.g., Invoice IDs) use semi-bold (`600`) at `#0F172A`.
- **KPI / Stat Cards**: Metric values use `metric-value` (22px bold `#0F172A`) to ensure rapid ocular scanning across horizontal panels. Metric descriptions remain understated at 12px `#64748B`.
- **Form Labels**: 12px with medium weight (`500`) `#475569`, providing clear spatial anchoring above 36px-tall input fields.

## Layout & Spacing

The interface uses a multi-tier dashboard layout:
1. **Left Navigation Drawer**: Fixed width of `240px` (collapsible to `68px`), anchoring navigation hierarchies and system categories.
2. **Top Header Bar**: Fixed height of `60px`, spanning the content canvas with an embedded search/locale switcher, badge notifications, and the user profile pill.
3. **Main Content Canvas**: Fluid grid using `gutter: 1rem` and `margin: 1.5rem`.
   - **Metrics Row**: 6-column flexible grid spanning summary cards (`Balance`, `Top Up`, `Used Credit`, `Sent`, `Paid`, `Refund`).
   - **Filter & Pill Row**: Inline flex layout with `0.5rem` spacing between segments and quick filters.
   - **Data Table**: Full-width bordered layout with `12px` vertical row cell padding and `16px` horizontal cell padding for maximum vertical efficiency without crowding.

## Elevation & Depth

This design system minimizes dramatic dropshadows in favor of crisp boundaries, light-refracting borders, and subtle containment:
- **Card & Panel Layer**: Cards rest on `#FFFFFF` with a single `1px solid #E2E8F0` border and a delicate ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04)`.
- **Primary Metric Spotlight**: The active "Balance" card features a distinctive double-highlight treatment: a tinted border `1px solid #10B981` with faint teal wash `rgba(16, 185, 129, 0.02)` to elevate the primary wallet balance above adjacent metrics.
- **Dropdown & Flyout Menus**: Elevated with `box-shadow: 0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.04)` surrounded by a `1px solid #E2E8F0` stroke.
- **Table Row Elevation**: Flat borderless rows delineated by `1px solid #F1F5F9` bottom dividing lines. Hover state introduces a flat `#F8FAFC` background shift without Y-axis translation.

## Shapes

The design system adheres to a crisp, enterprise-focused shape language:
- **Standard Corners (6px - 8px / `rounded-md`)**: Used for metric cards, table containers, inputs, date pickers, and rectangular action buttons.
- **Pills (9999px / `rounded-full`)**: Used for category filter tabs (e.g., `Invoice`, `Transaction`), status badges (`Success`, `Pending`), notification indicator dots, and avatar chips.
- **Compact UI Elements**: Checkboxes have a tight `4px` radius, maintaining industrial clarity.
